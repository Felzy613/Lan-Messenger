# FileTransferBanner

A glass capsule under the header that shows a file transfer's live progress.

## Rules
- A 32px `accent-wash` disc holding the transfer icon, then the label in `label-strong` ("Sending lan-messenger-2.0.0.pkg").
- The progress bar is 4px: a `brand` fill on an `inset-fill` track.
- The byte count is `code` (mono, tabular): "31744 KB / 51200 KB".
- It floats. The thread keeps scrolling under it.
