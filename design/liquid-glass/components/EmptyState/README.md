# EmptyState

What the sidebar or chat pane shows before there is anything in it.

## Rules
- A 64px clear-glass disc holding the icon in `ink-secondary`, a `title-pane` title, then a `label` explanation, at most 240px wide.
- The action is a primary Button with the verb the user will use: "New message".
- Copy says what to do next, not what is missing: "Tap “New message” to chat with one of your saved contacts, or add a new contact."
